## How to use the quizzes

1. Finish a module.
2. Open the corresponding quiz.
3. Read each question, **decide which answer you think is correct in your head**, then click the *Answer + reasoning* block to check.
4. Score yourself out of 5.

## Scoring rubric

- **5/5** — you've got it. Move on.
- **3-4/5** — solid. Re-read the section you were unsure about, then move on.
- **0-2/5** — re-do the module's notebooks before continuing. The next module builds on this one.

## Why multiple-choice (and not coding)?

Module notebooks already give you ~6-9 *write code* exercises each (Practice + Stretch). These quizzes test something different: **can you read code, predict its behaviour, and choose the right tool from a set of options?** That's the skill you need in code review, in interviews, and when reading other people's notebooks — and it's not the same skill as writing code from a blank page.

## Cross-references

Each quiz's closing cell links to the next module's first notebook. You can use the quiz as the natural transition between modules.
